# 🔐 Random Password Generator (Генератор случайных паролей)

**Автор:** Сергей Волков

## 📝 Описание

Random Password Generator — это мощное десктопное приложение для генерации надёжных случайных паролей с гибкими настройками. Приложение позволяет создавать пароли любой сложности, настраивать используемые типы символов, исключать похожие символы и сохранять историю всех сгенерированных паролей. Идеально подходит для повседневного использования, когда требуется создать безопасный пароль для различных сервисов.

## ✨ Функциональные возможности

- 🎚️ **Настраиваемая длина пароля** — от 4 до 64 символов с помощью удобного ползунка
- ✅ **Выбор типов символов**:
  - Заглавные буквы (A-Z)
  - Строчные буквы (a-z)
  - Цифры (0-9)
  - Специальные символы (!@#$%^&*)
- 🔧 **Дополнительные настройки**:
  - Исключение похожих символов (i, l, 1, L, o, 0, O)
  - Исключение неоднозначных символов
  - Обязательное использование всех выбранных типов символов
- 📊 **Оценка надёжности** пароля с визуальным индикатором
- 📋 **Копирование в буфер обмена** в один клик
- 📜 **История паролей** с датой, длиной и типами символов
- 💾 **Сохранение истории** в JSON-файл
- 📤 **Экспорт истории** в текстовый файл
- ✅ **Валидация ввода** (проверка на минимальное количество типов символов)
